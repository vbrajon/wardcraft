# Upgrades : les vrais chiffres
```
attaque   +1 : +12 %   +2 : +10,7 %   +3 : +9,7 %   (dés cachés)
armure    +2 par niveau = +12 % d'EHP, constant en absolu
coût      ~150-175  →  325-375  →  ~550 ressources
```
